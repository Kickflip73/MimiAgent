# 每日 AI 趋势 · 2026-08-16 讲解稿

大家好，这里是今天的 AI 趋势简报，覆盖最近三十天，也就是七月中旬到八月中旬。

先说四个最值得关注的核心判断。

第一，跨境 AI 并购撞上了国家安全审查的红线。Meta 对 Manus 母公司蝴蝶效应超过二十亿美元的收购，被中国外商投资安全审查以相关要求为由禁止。Manus 在八月十一号发了一封《致 Manus 用户的一封信》，宣布即将恢复以独立公司的形式运营。这是 AI Agent 头部公司第一次在国家安全审查层面被明确拦下来，意味着 AI 领域的跨境并购，正式进入了监管的深水区。

第二，编码 Agent 的产品形态，正在从「编辑器」进化成「任务编排中心」。Cognition 把 Windsurf 升级成了 Devin Desktop，也就是 Agent 指挥中心，最近又引入了 Kanban 看板，用来统一调度本地和云端的多个 Agent。AI IDE 的竞争焦点，已经从「代码补全加对话」，转向了「多 Agent 指挥台加任务编排」。

第三，国产开源模型把竞争推进到了「可编程 Agent 运行时」这一层。DeepSeek 发布了 V4-Pro 正式版，还上线了 DeepSeek Harness 的开发者预览，开源 agent harness、支持 Responses API。也就是说，国产模型的竞争维度，正在从「对话和推理能力」，转向「Agent 工具调用、运行时和协议」。

第四，基础模型和 AI 基础设施双线加速。Google 的 Gemini 3.1 Pro 用百万级上下文持续迭代，Anthropic 的 Claude 家族也在密集更新；同时伦敦的 AI 芯片公司 OLIX，单轮融资就拿了大约二点七亿欧元。模型的军备竞赛和算力基建的投资，正在同步升温。

下面说八条重点进展。

第一条，就是刚才提到的 Manus。八月十二号的消息，Meta 收购 Manus 的交易被禁止，八月十一号 Manus 宣布恢复独立运营。这笔交易对价超过二十亿美元，是今年最受关注的 AI Agent 并购案，也是第一次因为国家安全审查被否决，标志性很强。对行业来说，这是「本土独立」和「跨境整合」两条路线的分水岭；对创业者和投资人来说，跨境并购的结构、估值和合规成本，都被显著抬高了。

第二条，Cognition 把 Windsurf 升级成 Devin Desktop。产品定位从 AI IDE 转向 Agent 指挥中心，新版本引入 Kanban 看板，统一管理本地和云端 Agent。Cognition 本来就是 Devin 的作者，现在把两条产品线合并成一个「桌面 Agent 指挥台」，这是编码 Agent 产品形态的一次定义性升级。对开发者来说，工作流会从「人写代码、AI 辅助」，进一步走向「人派任务、多 Agent 协同执行」。

第三条，DeepSeek 发布 V4-Pro 正式版，并上线 Harness 开发者预览。V4-Pro 的 Agent 能力大幅提升，支持 Responses API；Harness 面向 agent harness 开发者，包含源代码。国产开源旗舰把「Agent 可编程性」当成了正式卖点，Harness 开源意味着开发者可以直接复用它的 agent 运行时，这对国产 Agent 生态的标准化是个好消息。

第四条，Google Gemini 3.1 Pro 持续迭代。它提供百万级上下文，以及多模态、多步任务的能力，同时 Gemini 3.5 版本的信息也开始出现。百万级上下文加多步 action，是 Agent 场景的关键底座，3.5 版本的临近，说明基础模型的竞争还在提速。

第五条，Anthropic 的 Claude 家族密集更新。近期涉及 Opus 4.7、4.8，Sonnet 4.6，Haiku 4.5，以及面向长文创作的 Fable，还有「Opus 5」作为长时运行 Agent 主力的说法。Claude 是编码和 Agent 场景的主力模型，这个版本线的快速迭代，反映的是 Agent 负载对模型能力提出的新要求。需要提醒的是，版本号目前有口径不一致的地方，Opus 4.8 和 Opus 5 的说法并存，这一条建议回官方公告再核实。

第六条，伦敦的 AI 芯片公司 OLIX Computing，完成了大约二点七亿欧元的 B 轮融资，约合三点一二亿美元。AI 芯片和硬件是现在资本密度最高的赛道之一，单轮接近三亿美元，说明算力基建的投资还在持续加码。

第七条，做 AI workers 自动化运营的 HappyRobot 完成了新一轮融资。这家公司在马德里和纽约，用 AI worker 来自动化后台运营任务。「AI worker」正在从概念走向可融资的落地形态，自动化运营是企业级 AI 一个很明确的方向，对传统的 RPA 和外包服务会形成替代压力。

第八条，OpenAI 的首席营收官 Dennis 离职，据科技媒体报道，这是近期第二位出走的核心高管。OpenAI 在商业化和高管稳定性上的动向，是观察行业头部公司组织变化的重要信号。

最后说明一下本次采集的情况。由于运行环境限制，Reddit、X、Hacker News 这些社区平台的互动数据这次没能拿到，所以没有提供星标、点赞这类量化热度指标；官方的一手发布页也因为沙箱直连受限，没能逐条抓取原文。上面这些事实，主要是通过 Bing 检索的快照交叉核验得到的，凡是我在文字简报里标注「建议复核」的条目，对外引用之前最好再回官方公告确认一下。
